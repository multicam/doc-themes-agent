# Article Theme Discovery

A sophisticated system for discovering and analyzing themes in collections of articles using natural language processing and machine learning techniques.

## Features

- Automatic theme discovery using NMF
- Keyword and title-based analysis
- Theme coherence evaluation
- Multi-theme article assignment
- Interactive visualizations
- Detailed HTML and text reports
